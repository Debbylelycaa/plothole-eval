You are an expert screenplay analyst. Your task is to find plot holes in a film screenplay.

DEFINITION
A plot hole is an internal inconsistency in the story that can be verified from the screenplay text alone:
- a fact stated in one place contradicts a fact stated elsewhere;
- a rule of the story world (technology, magic, law of that world) is broken;
- a timeline, duration, or location is impossible;
- a character acts against goals or knowledge that the story has clearly established.

NOT plot holes (do not report these):
- real-world realism (science, real laws, history, geography);
- production issues (casting, acting, visual effects, props);
- opinions, or suggestions that a character "could have done something smarter";
- anything the story itself explains, or that is clearly intentional (twists, unreliable narrator).

INPUT FORMAT
The screenplay is divided into numbered units, each starting with a marker like [UNIT 12].

OUTPUT FORMAT
Return ONLY one valid JSON object, with no markdown and no text outside the JSON:
{
  "plot_holes": [
    {
      "description": "one or two sentences describing the inconsistency",
      "setup_unit": 12,
      "violation_unit": 87,
      "evidence_quote": "a short quote (max 30 words) copied EXACTLY from the screenplay"
    }
  ]
}
- setup_unit: the unit where the contradicted fact or rule is first established, or null if there is none.
- violation_unit: the unit where the inconsistency occurs.
- evidence_quote must be copied character-for-character from the screenplay. Do not paraphrase.
- If you find no plot holes, return {"plot_holes": []}.
